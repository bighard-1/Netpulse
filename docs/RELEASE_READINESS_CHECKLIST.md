# NetPulse 商业级发布验收清单

本清单用于每次提交、构建镜像、升级生产环境前后确认系统处于可验收状态。目标不是追求一次测完所有细节，而是用固定步骤保护已经稳定的功能，降低回退和误伤概率。

## 1. 发布前代码检查

在本地执行：

```bash
./scripts/check_all.sh
```

必须确认：

- `go test ./...` 通过。
- `go vet ./...` 通过。
- `go build ./...` 通过。
- `npm --prefix web run build` 通过。
- 没有新增无关文件、临时文件、测试导出文件混入提交。

## 2. 数据库与迁移检查

升级镜像前确认：

- 已备份数据库。
- 容器环境变量 `TZ` 已固定为服务器期望时区。
- 数据库迁移不能在启动阶段执行长时间阻塞任务。
- 大索引、聚合修复、历史数据回填类任务应放到后台维护窗口执行。

升级后确认：

- 容器日志没有 `ensure schema failed`。
- `/api/system/ops` 能正常返回。
- 资产/数据库诊断页面没有 `critical` 项。
- TimescaleDB 连续聚合和 rollup 状态可查询。

## 3. 核心监控验收

至少抽测三类设备：

- 核心层设备 1 台。
- 汇聚层设备 1 台。
- 接入层设备 1 台。

每台设备确认：

- 设备在线状态正确。
- 端口 UP/DOWN/手动关闭状态正确。
- 设备详情页打开速度正常。
- 端口列表分页、搜索、上一端口/下一端口可用。
- CPU/内存图表无明显异常。

## 4. 端口流量图验收

每层级至少抽测一个端口：

- 当日曲线应快速显示。
- 近 7 日曲线应在可接受时间内显示，不应超时。
- 近 30 日曲线应使用聚合数据，不应长时间扫描原始指标。
- 自定义周期查询应按服务器时区展示。
- 图表不应因为浏览器本地时区变化而漂移。
- 图表断点应代表真实缺数据，不允许错误补 0 或错误连线。
- PNG/CSV 导出可用。

## 5. 仪表盘与高频入口验收

确认：

- 仪表盘首次进入无空白、无明显闪烁。
- 全局搜索可搜索设备、端口、备注。
- Ctrl+K 可用，不出现后端扫描错误。
- 实时事件流可展示设备状态变化、端口状态变化、重要告警。
- Top N 端口流量可展示并跳转端口详情。
- 拓扑图可展示、缩放、拖拽，普通用户不可编辑。
- 窄屏下侧边栏和右侧卡片不遮挡主内容。

## 6. 权限与安全验收

确认：

- 管理员可进入编辑模式并执行增删改。
- 普通用户只允许查看和查询，编辑入口隐藏或不可操作。
- 登录过期能回到登录页。
- API 错误不会暴露密码、Token、SNMP 团体字、数据库连接串。
- 备份恢复接口仅管理员可用。
- 上传恢复文件不能通过路径穿越写入任意位置。

## 7. 备份与恢复验收

确认：

- 备份任务可以创建。
- 前端能轮询任务进度。
- 备份完成后可以下载。
- 备份演练可以完成。
- 恢复入口能识别错误文件并给出明确提示。
- 大库备份不能依赖单个短 HTTP 请求一直等待完成。

## 8. 事件与日志验收

确认：

- 事件工作台可以按资产、事件类型、时间范围查询。
- 审计日志能记录关键管理员操作。
- 资产加载、端口流量、备份失败等问题能在诊断页看到原因或建议。
- 容器日志用于开发排障，前端提示用于用户理解，两者不要混淆。

## 9. 移动端验收

如本次涉及移动端，额外确认：

- iOS 登录、资产列表、设备详情、端口详情可用。
- iOS 流量图当日、7 日、30 日、自定义周期可显示。
- iOS 图表缩放、滑动读数、保存到相册可用。
- Android 如有改动，需验证同样路径。

## 10. 回退准备

发布前必须明确：

- 当前稳定镜像 tag。
- 新镜像 tag。
- 数据库备份文件位置。
- 如新版本异常，优先回退镜像；涉及数据库结构变更时，先评估是否需要恢复备份。
