# NetPulse 回归测试清单

本清单用于每次修复、优化、构建镜像前做最小验收。原则是：先确认已稳定功能没有被误伤，再验证新增改动。

## 1. 登录与权限

- 使用管理员账号登录 Web。
- 使用普通用户登录 Web，确认只读功能可用、增删改入口不可见或不可操作。
- 登录过期后能回到登录页，不出现循环报错。

## 2. 仪表盘

- 仪表盘首次进入能正常加载。
- 全局搜索可搜索设备、端口，并能跳转到对应详情。
- 拓扑图能展示节点在线/离线状态。
- 实时事件流能展示设备或端口状态变化事件。
- Top N 端口流量可以展示并点击进入端口详情。
- 全网健康趋势能正常显示，不出现压缩到角落的图表。

## 3. 资产中心

- 资产列表加载正常。
- 进入设备详情页速度正常。
- 设备详情页端口列表分页、搜索、返回顶部可用。
- 端口状态图标正确区分在线、离线、手动关闭。
- 端口名称、备注、百分比流量显示正常。

## 4. 端口详情与图表

- 当日流量曲线可快速显示。
- 近 7 日流量曲线可显示，不出现明显断点或加载超时。
- 近 30 日流量曲线可显示，不出现加载失败。
- 自定义时间范围查询可显示对应周期曲线。
- 图表导出 PNG 和 CSV 可用。
- 图表时间轴使用服务器时区，不随浏览器本地时区漂移。

## 5. 告警与日志

- 事件工作台可按时间、资产、事件类型查询。
- 审计日志能显示管理员关键操作。
- 资产/数据库诊断页能输出明确建议。
- 查询失败时前端提示友好，服务端日志保留详细原因。

## 6. 设置与备份

- 运行参数页面可加载。
- 备份任务可创建、轮询进度、完成后下载。
- 备份演练可正常完成。
- 恢复入口能识别非法文件并给出明确提示。

## 7. 移动端

- iOS 客户端可登录。
- iOS 资产列表、设备详情、端口详情可打开。
- iOS 当日、7 日、30 日流量图可显示。
- iOS 图表读数、缩放、保存到相册可用。
- Android 客户端如有改动，需单独验证登录、资产、端口、图表。

## 8. 构建检查

```bash
go test ./...
npm --prefix web run build
```

如本次涉及移动端，还需要执行对应平台本地打包。
